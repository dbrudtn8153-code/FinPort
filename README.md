# FinPort
## AI 금융 판단 코치 플랫폼

FinPort는 개인 투자자의 포트폴리오를 분석하고 리밸런싱, 종목 상세 정보, 투자 판단 코칭을 제공하는 웹 기반 금융 플랫폼입니다.

🔗 **배포 주소**: https://fin-port-phi.vercel.app

---

## 주요 기능

### 포트폴리오 관리
- 국내/해외 주식 및 ETF 실시간 현재가 조회
- 총 투자원금, 평가금액, 평가손익, 수익률 계산
- USD/KRW 환율 자동 반영
- 자산 비중 도넛 차트 시각화
- 목표 비중 기반 리밸런싱 추천 (매수/매도 수량 계산)
- 현금 비중 포함 포트폴리오 관리
- LocalStorage 기반 데이터 자동 저장

### 종목 검색
- 코스피 833개 + 코스닥 1,772개 + 한국 ETF 44개 (총 2,646개) 한글 검색 지원
- KOSPI / KOSDAQ / ETF 뱃지 표시
- 해외 주식 및 ETF 영문 티커 검색 (Yahoo Finance 연동)

### 종목 상세 페이지
- 실시간 현재가 및 등락률
- 52주 최고/최저가
- 거래량, 시가총액
- 주요 재무지표 (PER, PBR, 배당수익률, ROE)

### ETF 비교
- 두 ETF의 현재가, 1년 수익률, 배당률, 운용보수, 순자산 비교
- VOO vs QQQ, SCHD vs JEPI 등 인기 조합 빠른 비교

### 배당 계산기
- 투자금 기준 예상 연 배당 및 월 배당 계산

### 오늘의 투자 팁 / 용어
- 매일 바뀌는 투자 팁과 금융 용어 제공

## 기술 스택

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS
- **차트**: Recharts
- **데이터**: Yahoo Finance API (실시간 가격), KRX 공공 데이터 (종목 목록)
- **저장**: LocalStorage
- **배포**: Vercel

---

## 개발 배경

개인 투자자는 투자 과정에서 데이터보다 감정에 흔들리는 경우가 많습니다. 상승장에서는 추격 매수를, 하락장에서는 공포 손절을 하기도 하고, 특정 종목에 과도하게 집중하거나 현금 비중을 관리하지 못해 비합리적인 의사결정을 하기도 합니다.

FinPort는 포트폴리오 구조와 투자 행동을 분석해 리밸런싱과 위험 경고를 통해 더 합리적인 금융 판단을 돕기 위해 기획되었습니다.
